# Quick Start Guide

## 🚀 Get Started in 3 Steps

### Step 1: Start the Server
```bash
npm run dev
```
✅ Server running at http://localhost:3000

### Step 2: Edit Content
1. Go to http://localhost:3000/dashboard
2. Fill in your information
3. Upload images (optional)
4. Add books
5. Click "Save All Changes"

### Step 3: View Preview
1. Go to http://localhost:3000/preview
2. See your beautiful website!
3. Click "Refresh" after any changes

## 🎯 Common Tasks

### Upload an Image
1. Dashboard → Image Gallery section
2. Click "Choose File"
3. Select image (JPG, PNG, etc.)
4. Wait for "Image uploaded successfully!"

### Add Multiple Books
1. Dashboard → Books section
2. Click "+ Add Book"
3. Fill in details
4. Repeat for each book
5. Click "Save All Changes"

### Update Existing Content
1. Dashboard → Edit any field
2. Make changes
3. Click "Save All Changes"
4. Preview → Click "Refresh"

## ⚠️ Important Rules

### ✅ DO:
- Use plain text only
- Upload images under 5MB
- Save changes before previewing
- Check preview after saving

### ❌ DON'T:
- Enter HTML tags
- Use script tags
- Enter URLs directly
- Upload non-image files

## 🔒 Security is Automatic

The app automatically:
- ✅ Blocks script tags
- ✅ Escapes HTML
- ✅ Validates file uploads
- ✅ Sanitizes all content
- ✅ Prevents code injection

You just focus on content! 🎉
